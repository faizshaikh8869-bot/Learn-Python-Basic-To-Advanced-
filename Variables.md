
## Rules 
# - Variable can start with char or _ and 
# - must not start with digit or special character or resorved words 
# - Case Sensitivity
# - No Special Characters: Spaces, hyphens, and symbols like @ or $ are invalid in variable names
# - Dynamic Typing: The variable type is inferred from the assigned value and can change upon reassignment (e.g., x = 1 then x = "string").


## Best Practices 
# - Snake Case: The standard convention for multi-word names is snake_case (lowercase words separated by underscores, e.g., user_name). 
# - Best Practices: Names should be descriptive (e.g., total_price instead of tp) and avoid overly short or ambiguous single letters.
